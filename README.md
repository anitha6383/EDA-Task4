# Task 4 – Advanced Analytics & Statistical Modeling

## Objective

Apply statistical analysis, customer segmentation, and basic predictive modeling using the Superstore Sales Dataset.

## Dataset

Superstore Sales Dataset

## Activities

- Performed descriptive statistical analysis.
- Conducted hypothesis testing.
- Analyzed relationships between important variables.
- Applied customer segmentation using clustering.
- Built a basic predictive model for sales.
- Evaluated model performance using standard metrics.
- Identified the top important features influencing sales.

## Key Findings

1. Discount has the strongest influence on Sales.
2. Quantity has a positive influence on Sales.
3. Increasing Quantity is associated with higher Sales.
4. Higher Discount is associated with lower Sales in this model.
5. The results can support pricing and sales strategy decisions.
